kiro-cv is a developer portfolio that looks and feels like the real Kiro CLI. Visitors explore your experience, skills, and certifications using slash commands — just like Kiro. Plain text input triggers an AI chat that responds in character as you. It is weird, it is fun, and recruiters actually love it.

## ✨ What Is kiro-cv?

kiro-cv turns a normal portfolio into a terminal-style experience. Instead of scrolling through a long page of text, visitors type simple commands to explore your background. The screen looks like a modern terminal window, with a clean prompt, clear responses, and a familiar input area.

The portfolio is built for people who want something more memorable than a standard CV website. Recruiters can quickly jump to the sections they care about. Hiring managers can ask questions in plain English. Curious visitors can play with the chat and learn about your work in a way that feels natural and interactive.

The experience has two main parts:

- Slash commands let visitors move through your portfolio like they are using Kiro.
- Plain text input opens an AI chat that responds in character as you.

Both parts work together. A visitor can type a command to view your experience, then ask a follow-up question in normal language. The result feels like a conversation with a portfolio, not a static document.

## 🚀 What You Can Explore

The portfolio is organized around the details recruiters and collaborators usually look for. Visitors can explore:

- Work experience and previous roles.
- Technical skills and tools.
- Certifications and professional credentials.
- Background and career highlights.
- Contact information and next steps.

Each area is available through a slash command. This makes the portfolio easy to scan without forcing visitors through every section in order. Someone who only wants to see certifications can go straight there. Someone who wants a broader view can start with the help command and follow the list.

The AI chat adds another layer. Visitors can ask questions such as “What are your strongest skills?” or “Tell me about your last role.” The chat responds in character as you, using the portfolio content as its source. It keeps the experience playful while still giving useful answers.

## 🖥️ How It Works

When the application opens, visitors see a terminal-style window. There is a prompt, a message area, and an input field. The prompt is where visitors type. The message area shows responses. The input field is where commands and chat questions are entered.

Slash commands start with a forward slash. For example, a visitor might type /help to see what is available. The application reads the command and displays the matching section. Plain text without a slash starts the AI chat. The application treats the text as a question and replies in character as you.

The interface is designed to feel like Kiro CLI, but it does not require any developer knowledge. Visitors do not need to install a terminal, configure settings, or run scripts. They simply open the application, type in the input area, and press Enter.

The layout is intentionally simple. There are no complicated menus, hidden panels, or setup screens. The main interaction is typing. This makes the portfolio approachable for recruiters who may not be technical, while still giving developers and terminal fans a familiar experience.

## ⌨️ Using Slash Commands

Slash commands are the fastest way to move around the portfolio. A command begins with a forward slash and a short word. The application recognizes the command and displays the matching content.

Common commands include:

- /help shows the list of available commands.
- /experience displays work history and roles.
- /skills shows technical skills and tools.
- /certifications lists professional credentials.
- /about shares background and career highlights.
- /contact shows ways to get in touch.

Visitors do not need to remember every command. The help command is always available and provides a clear starting point. After viewing a section, visitors can type another command to jump somewhere else. The message area keeps the most recent responses visible, so it is easy to follow the conversation.

Slash commands are intentionally short. This keeps typing quick and makes the portfolio feel like a real terminal tool. A recruiter can type /skills and see the most relevant technical information in seconds. A hiring manager can type /experience and review roles without scrolling through unrelated content.
